# Colorful Originals 风格规范 · 1.1

适用于新增的 1,000 个原创图标。目标是同一套圆润、轻盈的小物件插画，使用已有三色主题和动效 API。规范源为 `packages/icons/design/originals/style.mjs`；绘图源仍按各自物件保存，不覆盖原有 1,519 个图标。

## 轮廓与圆角

| 项目 | 规范 |
| --- | --- |
| 画布 | 24 × 24，透明背景，默认实际检查尺寸 26 px |
| 大色块转角 | 随部件短边确定，半径上限 1.25；柔化柜体、琴箱、建筑的硬转折 |
| 小部件转角 | 半径下限 0.55，短边与相邻曲线限制实际切角，保留鸟喙、夹齿、工具尖端的语义 |
| 矩形部件 | 优先使用圆角，上限基准 1.6；已有更大的合理圆角保留，不超过短边一半 |
| 结构线 | regular 1.1，圆端点、圆连接，不用完整深色外描边围住主体 |
| 留白与重心 | 常规主体约在 2…22 内；狭长工具、横向车辆独立检查，禁止统一拉伸或撑满包围盒 |

圆角是制作规则，不能代替物件设计。先画出真实轮廓，再柔化转折；保留动物生长方向、衣物褶皱、曲面器皿等自然曲线。不得添加通用底板或随机波浪切面。

## 三色与部件关系

- `surface` 是浅层主体或前方部件，`back` 是主体局部或后方部件，`detail` 是结构线和少量识别点。每枚必须实际包含前两种填色。
- 每块颜色能说明它是什么，例如扶手、琴箱、液面、翼片；以一个包裹、承托或前后关系为主。
- 一般两至三层颜色，不用阴影、渐变、透明度叠加制造第四种色阶。无背景徽章。
- 深色主题使用组件包已校准的主题 token；不将整枚图标降低透明度。

## 细节密度

先在 26 px 下判断是否需要该细节。通常只保留一至三组识别结构，例如器皿开口、衣领、门扇、乐器琴弦。语义相关的重复部件可成组出现。

自动门槛为最多 8 条独立线段轮廓、结构线总长度不超过 60 画布单位；它们用于发现异常，不能替代目视判断。太阳光芒、芯片引脚允许有规律的 8 条轮廓。窗格、琴键、网格优先减少重复，真实框架可改为浅色或主色色块，禁止自动按长度删线。

本轮专门修订足球门、排球网、椭圆机、管风琴、扬琴、锣、陀螺仪、试管架、芯片、雷达、温室、手风琴、面包板、上下铺和软枕；坐姿猫、刀具、车辆等通过明确记录的位移校正重心。

## 六种样式与动效

四档结构线宽继续使用 0.45 / 0.75 / 1.1 / 1.8。fill 保留全部识别结构，duotone 加强两级色块对比；同一物件在六种样式里不改变语义或丢失元素。

前后色块与细节分别进入既有动画层；入场、悬停形变与镜像过渡沿用公共实现。不能用整体晃动替代分层动画，也不为不同图标加入随机缓动。检查加粗边界，并在页面验证形变回位。

## 生成与验收

1. 修改物件绘图源，运行 `npm run originals`。统一样式在生成 regular 前应用。
2. `npm run test:originals -w @colorful-icons/react` 同时检查数量、重复几何、样式密度、三色、圆角与源文件一致性；不合格时拒绝写入资产。
3. `npm run preview:originals -w @colorful-icons/react` 输出 20 张带名称的 50 / 26 px 联系表，逐张复查。另在深色背景检查代表性物件。
4. 组件测试、全量圆角和六种样式边界检查通过后，构建组件包与官网，更新 SVG 压缩包。

`design/originals/review/style.json` 是全量样式报告，`geometry.json` 是几何报告；`design/archive/0.7.0-originals` 保留修订前 SVG，可用于复核。原始绘图源与生成资产分别保存，避免后续重建丢失修订。
