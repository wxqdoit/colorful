# Colorful 图标系统设计规范 · 1.2

> 适用于 Colorful 全量 2,519 枚图标（包括 1,000 枚全新原创插画图标与 1,519 枚重绘符号及经典图标）。本规范定义了整套图标的视觉哲学、空间栅格、色彩架构、描边形态、曲率圆角、分类绘制规则、分层动效及工程质检标准。

---

## 一、 核心设计哲学

Colorful 图标库的设计目标是为现代数字界面带来**有温度、轻盈、柔和、富有个性**的视觉体验。整套系统遵循以下四大核心原则：

### 1. 色块即物件（Form Follows Object）
- **色块必须是物件本身**：书页是色块、杯身是色块、头肩是色块、云朵是色块、星球与水滴也是色块。
- **严禁无意义通用底框**：不将通用线性图标随意贴在一团圆形、方形或圆角方形的背景底板上。除语义本身就是纸张、便签、屏幕、画框或特定徽章外，所有图标均采用无底板的自然轮廓。
- **部件分色与层叠关系**：每块填色都应能清晰解释物件的体积、材质或前后遮挡关系（例如：前层扶手与后层靠背、折叠纸张的内外面、杯体与液面）。

### 2. 细线辅助结构（Linework as Structure）
- **线条是骨架而非轮廓描边**：细线不包办物件的完整外轮廓，而用于交代关键结构——如书脊、纸页折痕、杯口边缘、轨道、缝线、衣领、钟表指针或核心识别点。
- **精炼与克制**：在 24 画布基准下，通常仅保留 1～3 组有价值的结构线。坚决剔除在小尺寸（26px）下会模糊粘连的细碎装饰与高密纹理。

### 3. 柔和圆润与手绘呼吸感（Softness & Organic Balance）
- **彻底消除尖锐死角**：全库所有闭合几何与开放笔画转折均采用切线连续的圆润曲率，杜绝生硬冷峻的直角尖刺。
- **自然生长与轻微不对称**：允许符合物理规律或生命形态的轻微不对称与层间错位，呈现富有呼吸感的插画气质，同时严格保持小尺寸下的快速识别度。

### 4. 纯净透明与无侵入（Clean & Transparent）
- **默认透明背景**：SVG 画布背景全透明，不覆盖宿主容器底色。
- **扁平两到三层**：仅通过表面层与主色层的明暗色阶形成空间深度，默认不使用渐变、径向模糊、外发光或拟物投影。

## 二、 画布、栅格与空间尺寸

### 1. 画布与视口（Canvas & ViewBox）
- **统一视口**：`viewBox="0 0 24 24"`，采用统一 24×24 单位矢量坐标系。
- **渲染基准**：默认实际检查尺寸与卡片图标尺寸为 `26 × 26 px`。SVG 根元素统一输出 `width="26" height="26"`，并通过 CSS / React props 实现等比无级缩放。
- **推荐显示阶梯**：
  - 小尺寸应用：`18px` / `20px` / `24px`
  - 卡片与列表默认：`26px` / `32px`
  - 重点引导与展示：`48px` / `56px` / `72px`

### 2. 安全区域与活跃边界（Safe Zones & Padding）
- **常规安全区域**：主体几何核心分布在 `[2, 2, 22, 22]` 范围内，四周保留至少 1～2 单位的内边距。
- **符号与高重心紧凑区**：方向箭头、数学运算符号及对齐标尺分布在 `[3, 3, 21, 21]` 范围内。
- **描边裕量（Stroke Bleed）**：考虑 Bold（加粗 1.8）与 Fill（微描边）模式，所有路径加上半径 `0.9px` 的描边后，绝对边界不得超出 `[0, 0, 24, 24]`，避免导出或切图时发生像素裁切。

### 3. 视觉重量与光学校正（Optical Weight Compensation）
- **禁止机械拉伸撑满**：视觉感知面积因几何形态而异。正方形或饱满圆形若撑满 24 单位会显得过于笨重，而细长工具或车辆若缩入小方框则会显得纤弱。
- **几何面积补偿原则**：
  - 正方形/实心圆：外延收敛至 16～18 单位；
  - 三角形/菱形：顶点适度外延至 19～20 单位；
  - 细长物件（笔、尺、筷、球棒）：对角倾斜布局，最大化利用空间；
  - 宽扁物件（汽车、公交、长椅）：横向展开，高度自然收拢。
- **非对称物件重心位移表（Optical Offsets）**：
  对特定物理物件进行显式微距平移，确保其视觉重心与 24×24 中心严格重合：
  - `sitting-cat` (坐姿猫): `translate(1 0)`
  - `claw-hammer` (羊角锤): `translate(0 -0.7)`
  - `oyster-knife` (生蚝刀): `translate(0 1)`
  - `paring-knife` (削皮刀): `translate(0 0.7)`
  - `articulated-bus` (铰接客车): `translate(0 -1)`
  - `articulated-lorry` (铰接卡车): `translate(0 -0.7)`
  - `go-kart` (卡丁车): `translate(0 -1)`
  - `quad-bike` (全地形车): `translate(0 -0.7)`
  - `footrest-ottoman` (脚踏凳): `translate(0 -0.7)`
  - `flowering-tea` (开花茶): `translate(0 -0.7)`

## 三、 色彩架构与语义 Token

Colorful 采用语义化三色分层体系，所有资产严格使用 CSS 变量（带十六进制标准回退）。

```
        ┌──────────────────────────────────────────────┐
        │                 ICON ARTWORK                 │
        │                                              │
        │   ┌──────────────────────────────────────┐   │
        │   │  --project-art-surface (浅层/纸面)   │   │
        │   └──────────────────┬───────────────────┘   │
        │                      │ 相互交叠              │
        │   ┌──────────────────┴───────────────────┐   │
        │   │  --project-art-back (主体/体块/后层)  │   │
        │   └──────────────────┬───────────────────┘   │
        │                      │ 结构交代              │
        │   ┌──────────────────┴───────────────────┐   │
        │   │  --project-art-detail (细线/识别点)  │   │
        │   └──────────────────────────────────────┘   │
        └──────────────────────────────────────────────┘
```

### 1. 核心语义 Token
| 语义用途 | CSS 变量 Token | 浅色主题 (Light) | 深色主题 (Dark) | 作用说明 |
| :--- | :--- | :--- | :--- | :--- |
| **浅层主体 / 纸面** | `--project-art-surface` | `#f0e9f8` | `#38313f` / `#746188` | 处于前层的物体部件、纸张正面、高光承托面、浅色器官 |
| **主色体块 / 后层** | `--project-art-back` | `#d9c9ed` | `#625576` / `#af94ca` | 物体主体体积、后方部件、阴影面、主要材质色块 |
| **结构细线 / 核心点** | `--project-art-detail` | `#aa8bcf` | `#c4acd9` / `#efdcfa` | 骨架描边、特征线条、眼睛瞳孔、纽扣、标牌刻度 |
| **局部轮廓 (可选)** | `--project-art-outline` | `#b39acd` | `#9580aa` | 辅助外边线（需要微弱对比时的过渡色） |
| **纹理细节 (可选)** | `--project-art-stripe` | `#aa8bcf` | `#bca3d4` | 斑马线、编织网纹、百叶窗等条纹线段 |
| **点睛强调 (可选)** | `--project-art-accent` | `#8b65b5` | `#c9afe5` | 少量强调核心标记点，克制使用 |

### 2. 双主题与深色模式规范
- **原生多级映射**：深色模式分别重设 `surface`、`back`、`detail` 对应明度的暗色变量，确保在黑色/暗灰背景下依然具有通透分层。
- **严禁整图反色**：绝对禁止通过 `filter: invert(1)` 或简单降低全局 `opacity` 实现深色模式，否则会破坏柔和插画原本的明暗深度逻辑。

### 3. 八大预设调色板（Palette Presets）
系统内建 8 组经典和谐调色板，可由 `preset` 属性直接激活或自由扩展：
1. **Lavender (浅紫 · 默认)**: 雅致温柔，高辨识度与艺术感。
2. **Mint (薄荷绿)**: 清新自然，适合生态、健康、金融工具。
3. **Peach (蜜桃橙)**: 温暖活泼，适合生活、美食、社区产品。
4. **Ocean (海盐蓝)**: 广阔专业，适合科技、企业、协作系统。
5. **Rose (玫瑰粉)**: 浪漫柔美，适合美妆、时尚、情感表达。
6. **Sand (暖杏沙)**: 质朴沉稳，适合家居、建筑、人文内容。
7. **Graphite (石墨灰)**: 高级克制，黑白灰界面的柔和插画搭档。
8. **Tangerine (橙柠撞色)**: 明快醒目，适合突出动态与创意入口。

## 四、 描边系统与六种形态

### 1. 基础线宽梯度
SVG 根元素统一设置 `stroke-width="1.1"`，在四档线性风格中等比衍生：
| 样式 (Weight) | 线宽 | 特性与适用场景 |
| :--- | :--- | :--- |
| **Thin** | `0.45` | 极细若丝，用于高分辨率视网膜大屏、细腻背景或极简极客风格 |
| **Light** | `0.75` | 纤细柔和，用于信息密度较高的后台看板或小标题搭配 |
| **Regular** | `1.1` | **核心设计基准**，线条与色块达到最佳视觉平衡，默认通用 |
| **Bold** | `1.8` | 粗体强调，突出层级与动作焦点，小尺寸高反差识别极强 |

### 2. 面与双色衍生风格
- **Fill（纯色块饱和态）**：
  - 保留所有结构与识别要素；
  - 对非 `none` 的封闭形状，描边色设为与填色相同，并叠加 `0.55`（主色）或 `0.2`（细节色）的微轮廓，使小插画在无边线模式下依然轮廓饱满清晰。
- **Duotone（双色对比态）**：
  - 强化主色与浅色两级的体块明暗反差；
  - 将除浅层纸面（surface）之外的所有着色形状映射为深度对比色，呈现双色网印版画的艺术质感。

### 3. 描边几何规则
- **端点与连接**：全库所有描边元素严格声明 `stroke-linecap="round"` 与 `stroke-linejoin="round"`。
- **细节复杂度门槛**：
  - 单枚图标内结构线总长度不超过 **60 画布单位**；
  - 独立开放线段轮廓不超过 **8 组**（太阳光芒、芯片引脚等有规律阵列除外）；
  - 坚决杜绝在 24 画布下绘制密集窗格、密集琴键或微小表格线条。

## 五、 圆角与曲率标准

### 1. 彻底切角化（Filleted Corners）
- 任何相交折角，夹角若大于 **1 度**，必须经过切线平滑圆角处理，严禁保留尖锐角点。
- 相邻曲线与直线过渡必须保证一阶导数连续（相切平滑），无突兀拐点。

### 2. 半径分级控制
- **大色块曲率（Fill Radius）**：
  - 下限：`0.55`（保证微小部件如鸟喙、拉链齿、工具尖锐部位的识别语义不失真）；
  - 上限：`1.25`（柔化柜体、建筑物、机器箱体的生硬边缘）；
  - 动态适应公式：`radius = Math.min(1.25, Math.max(0.55, shortSide * 0.12))`。
- **矩形与面板曲率（Rectangle Radius）**：
  - 最大基准：`1.6`（不得超过短边的一半）；
  - 动态适应公式：`rx = Math.min(width/2, height/2, Math.max(rx, Math.min(1.6, minSide * 0.25)))`。

### 3. 封闭轮廓曲线规范
- 主要色块优先使用带 `C`（三次贝塞尔）、`Q`（二次贝塞尔）或 `A`（椭圆弧）的闭合路径，并始终以 `Z` 严格封闭。
- 填色图元必须显式标注 `stroke="none"`，避免继承根描边导致形状轮廓畸变膨胀。

## 六、 35 大分类具体设计标准

全库 2,519 枚图标划分为 35 个领域分类，各领域遵循针对性的设计准则：

### 1. 现实物件与生活用品（家居、厨房、穿搭、手作、个护、生活、物件）
- **造型要求**：取材真实生活用品的三维透视或正视投影，用前后两层色块分别表达正面/内衬/把手/承托底座。
- **部件分色**：
  - 杯壶碗碟：杯身为主色，内壁或液面为浅色，杯把与边缘为细线；
  - 椅子沙发：软包坐垫为浅色，靠背与框架为主色，缝线与腿为细线；
  - 衣服鞋包：衣身为主色，衣领/口袋/折边为浅色，拉链与褶皱为细线；
  - 手作工具：手柄为主色，金属刃部或咬合面为浅色，刻度与转轴为细线。

### 2. 自然生灵与地理生态（动物、植物、食物、饮品、地貌、天气、自然）
- **造型要求**：注重自然生命体饱满舒展的生长态势，用圆润的闭合曲线勾勒有机轮廓。
- **部件分色**：
  - 动物：躯干为主色，腹部/耳蜗/面颊/鸟翼为浅色，眼睛与胡须为点睛细节；
  - 植物：叶片/花瓣为主色，花蕊/叶脉折光面为浅色，茎秆与纹理为细线；
  - 食物：外皮/面包为主色，夹心/糖霜/截面为浅色，点缀细节为深色芝麻或果仁；
  - 天气地貌：山脊/云体为饱满大曲线，前后层叠错落，阳光与雨线为圆润胶囊形态。

### 3. 人物、角色与日常交互（人物、常用、媒体、游戏、商业、办公、健康、旅行）
- **造型要求**：头肩比例匀称，体态松弛有度，拒绝呆板生硬的火柴人造型。
- **部件分色**：
  - 头肩肖像：头发与服饰为主色，面部与领口为浅色，五官与眼镜为精炼细线；
  - 卡片与文稿：外壳或封套为主色，纸面为浅色，文本排版用 1～3 组胶囊横线示意；
  - 医疗健康：胶囊、药丸、仪器按物理分隔分色，红十字或心电曲线转折完全圆滑。

### 4. 科学、技术与交通建筑（科技、科学、建筑、出行、运动、艺术、设计）
- **造型要求**：兼顾工程严谨感与插画柔和感，软化机械转角与金属冷感。
- **部件分色**：
  - 科学仪器：试管/烧瓶外壁为细线，内部液面为浅色与主色分层，试管架与刻度为辅助线；
  - 车辆交通：车身为主色，车窗与车顶为浅色，轮毂、车灯与路面为结构细线；
  - 建筑场馆：墙体与屋顶形成高低纵深，门窗以圆角方块或圆拱嵌入，避免密密麻麻的砖缝。

### 5. 方向、布局、文字与数学（方向与布局、文字与运算、功能符号）
- **造型要求**：功能符号以结构清晰为最高优先级，不强行堆砌无关插画底板。
- **部件分色**：
  - 箭头类：箭头头部或活动端点承担局部主色块，轨线为标准细线；
  - 对齐与布局：对齐基准线与被对齐的几何块形成深浅互衬；
  - 数学与排版：纯运算字符（加减乘除、等号、大括号）保持圆头圆角开放线稿，复杂排版符号（文本块、段落）融入浅色承托面。

### 6. 品牌标识与第三方徽标（品牌标识）
- **造型要求**：严格忠于各品牌的核心识别特征与轮廓比例，但在转折与棱角处融入 Colorful 统一的圆角语言。
- **部件分色**：将单色品牌剪影巧妙转化为前浅后深的双层柔和色块，保留品牌独特的空间构造与微小识别特征（如 Apple 叶片、Twitter 翅膀、GitHub 猫耳、Windows 四扇透视窗）。

## 七、 分层动效设计体系

Colorful 图标内置分层动画引擎，利用 SVG 内部结构层实现独立而自然的微交互：

### 1. 动效结构分层
- `[data-colorful-entrance]`：负责整枚图标的入场出场变换容器。
- `[data-colorful-hover]`：负责用户悬停时的动态响应容器。
- `[data-colorful-mirror]`：负责水平镜像翻转变换容器。

### 2. 入场动效（Entrance）
- **`pop`（弹性展开）**：缩放由 0.7 弹性反弹至 1.05，最终回弹稳定至 1.0，轻快愉悦。
- **`rise`（向上浮现）**：Y 轴由 +3px 位移平滑上浮归位，伴随透明度由 0 至 1。
- **`fade`（柔和淡入）**：透明度淡入过渡，适合大批量列表加载。

### 3. 分层悬停动效（Layered Hover）
- **`lift`（轻跃登场 · 推荐）**：图标向上微浮 0.8px，并带有 -2 度的轻微倾斜，模拟卡片微抬手感。
- **`wiggle`（俏皮摇摆）**：以底部为支点产生 0° → +4° → -4° → 0° 的短促灵动摆动。
- **`pulse`（气泡鼓起）**：轻微缩放 1.0 → 1.06 → 1.0，富有呼吸韵律。
- **`spread`（纸片绽放）**：内部浅色面与主色面沿对角方向产生微差位移，突出分层物理感。
- **`morph`（软糖回弹）**：路径轮廓轻微受力形变并回弹，宛如柔软胶糖。

### 4. 无障碍与动效减弱（Accessibility & Reduced Motion）
- 组件内置感知 `@media (prefers-reduced-motion: reduce)`；
- 当系统偏好减弱动态效果时，所有入场与悬停形变自动禁用，立即呈现最终静态画面。

## 八、 质量验收与自动化检测矩阵

所有纳入版本的图标必须 100% 通过自动化质检流程方可写入交付资产：

```
                 AUTOMATED VERIFICATION PIPELINE
```
