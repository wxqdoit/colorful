# Colorful Implementation Plan

**Goal:** 交付 24 枚柔和插画图标和可复用 React 包。
**Architecture:** SVG → 生成 weights → CSR/SSR → Vite preserveModules。公共渲染逻辑与 Context 隔离。
**Tech Stack:** TypeScript、React、Vite、SVGR、Vitest。
**Spec:** `docs/superpowers/specs/2026-09-11-colorful-design.md`

## 全局约束

24 单位画布、26px 默认、6 weight、六个颜色 token、React >=18、Node >=22；源 docs 不改；CSR/SSR 分离；只本地构建。

## 执行步骤（本会话顺序实施）

- [x] 1. 定义核心公开行为测试：默认样式、Context 覆盖、palette、theme、alt、SVG children、ref、SSR。先运行确认缺少实现，再添加 `src/lib/{types,context,palette,render,IconBase,SSRBase}`。
- [x] 2. 绘制 `assets/regular/*.svg`，复制三枚参考资产，建立 catalog。实现 `scripts/assemble.ts`：验证名称/资产，SVGR 转 JSX，生成 defs / CSR / SSR / 入口 / 其它 weight SVG；`--check` 比较生成结果。
- [x] 3. 配置 `vite.config.ts`、声明生成、包 exports、use client 保留。通过 `npm run build` 与 `scripts/test-package.mjs` 验证 require/import/server condition/tree shaking。
- [x] 4. 实现 `example/src` 图标浏览器，筛选和尺寸等控件使用本地 React 状态。选中图标导出真实 SVG，复制可直接使用的 JSX。
- [x] 5. 更新 README 与上游差异/许可说明。运行 `npm run check`，实际浏览器检查 26px/放大、浅深主题、移动端、搜索/空态/选择/下载。修复发现的问题后交付启动方式与验证结果。

验证记录：`npm run check` 覆盖组件、类型和打包消费；内置浏览器验证搜索、分类、空态、复制、主题、尺寸、镜像、390px 布局与 SVG 曲线边界。内置浏览器的下载策略会取消 blob 保存，提供「复制 SVG」可交付相同的独立 SVG 内容。
