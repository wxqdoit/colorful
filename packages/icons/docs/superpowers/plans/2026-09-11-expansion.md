# 三色、动效与全目录改造

用户授权范围：入场与 hover 动画；镜像过渡；三色自由配色及预设；审阅 Phosphor React 全部图标并改造适合者。

- [x] 将渲染颜色限定为 surface/back/detail。保留旧 palette 键为 detail 的兼容别名，源 SVG 统一三色。
- [x] 提供六组深浅预设、组件 preset prop 和独立三色覆盖。预览中可直接编辑颜色并复制当前配置。
- [x] 用独立 SVG 分组承载镜像、入场和 hover；使用可选 motion.css，支持重播与 reduced motion，SSR 不依赖 Context/hooks。
- [x] 固定上游 React/core 版本，审阅 1512 枚图标的原始矢量和元数据。为每项记录纳入或排除的依据。
- [x] 将合适的实体/场景/状态图形转成主体色块、物件内部的曲面分层和少量结构线；不为纯线性符号强加背景容器。保留原有自绘资产。
- [x] 生成全量组件、预览搜索与分页、可复现覆盖报告，补充上游 artwork MIT 署名。
- [x] 验证三色约束、动画/镜像/配色继承、SSR、全量输出和打包，浏览器检查多组实际图形和交互。

适合的定义：有可辨认主体面积的非品牌图形；排除纯箭头/文字/数学符号、仅排版编辑线条及缺少可用色块的几何操作符。包含实体、自然、旅行、媒体、人物、文档、控件等；是否纳入按每个文件的轮廓与语义共同判定。报告列出每项结论，未改造项不会伪装成已完成。


验证结果：最终 1,053 枚（24 枚原有 + 1,029 枚改造），覆盖上游 1,512 枚，17 枚复用，466 枚排除。20 项测试通过；全量 1,053 枚路径检查无非有限值或越界。ESM / CJS / UMD / 类型构建通过，打包入口、React Server 条件、类型消费、tree shaking 验证通过。预览构建通过，首屏只加载 48 枚图标模块。

浏览器检查：浅紫、薄荷、蜜桃、海盐及深色主题；三色独立输入与代码输出；自然、旅行、鼠标区域变体抽查；320ms 镜像 transition、560ms 初始动画及错峰、hover 摇摆；reduced motion 关闭动画并保留镜像；390px 布局无横向溢出。全量是自动矢量转换并进行分类抽检，未声称逐枚手绘审核。
