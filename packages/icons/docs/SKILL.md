# 柔和色块插画图标

把图标画成同一套插画里的小物件：用圆润的封闭色块构成主体，用少量细线交代结构与细节。默认采用浅紫、轻盈、平面的分层插画风格，保持小尺寸下的辨识度。

## 先确定设计对象

从用户提供的功能名称、含义、使用位置和参考图开始。已知信息直接使用；没有指定时，按以下默认值执行：

- 交付可编辑 SVG；已有 React 项目则沿用项目组件方式。
- `viewBox="0 0 24 24"`，卡片中显示为 26px，透明背景。
- 一项功能对应一个独立造型，整套共用比例、色阶和线条规则。
- 用户给了参考插画时，同时匹配它的轮廓、填色面积、叠层关系和细节密度；不要只提取颜色。
- 用户只要求改图标时，保持卡片、文字、按钮和选中交互的范围不变。

画图前，查看 [书本](assets/story.svg)、[场景](assets/scene.svg)、[水彩](assets/watercolor.svg) 三个实例。它们分别展示折页结构、层叠景物和有机液滴；不要把其中某个造型机械复制到所有主题。[预览页](assets/preview.html) 可同时检查浅色和深色背景下的实际尺寸与放大效果。

## 核心视觉规则

### 色块就是物件

- 主体轮廓先由色块成立：书页是色块，人物头肩是色块，杯身、星球、液滴也是色块。
- 不把通用线性图标放在一团任意形状的底色上。色块必须解释物件的体积、局部结构或前后关系。
- 一般使用一层浅底、一层主色和少量深色细节。浅底也应是物件本身的一部分。
- 保持无容器底框。不要为每个图标添加相同的圆形、方形、圆角方形徽章；语义本来是纸张或画框时，可以保留对应轮廓。
- 整体读感是圆润、轻盈、清晰的小插画，避免厚重墨线、金属高光、拟物质感和立体挤出效果。

### 封闭曲线造型

- 主要色块优先使用带 `C` / `Q` / `A` 的 SVG 闭合路径，并以 `Z` 结束。
- 让曲线随物件变化：水滴、花瓣、豆形、波浪、柔和月牙、圆润头肩、略有弧度的纸页等。
- 圆、椭圆和圆角矩形可以用于局部结构；不要让所有图标的主色块变成同一种几何底板。
- 转折保持圆滑，控制点形成连续曲线。避免多边形硬折角、自交、突兀尖刺和随机抖动。
- 允许轻微不对称和层间错位，呈现手绘插画的自然感；不要扭曲功能识别。
- 色块可以与细线轻微错位，但不能无目的地溢出整个图标。

### 线条是辅助信息

- 线框与色块共同构图；不必沿每块填色完整描边。
- 线条主要表达书脊、纸页折痕、杯口、轨道、表情、笔尖分界等。
- 24 单位画布默认 `stroke-width="1.1"`，必要时在 1.0–1.25 间微调；整套保持一致。
- 使用 `stroke-linecap="round"` 和 `stroke-linejoin="round"`。
- 一般保留 1–3 组有意义的细节线，优先删掉缩小后会糊成一团的纹理与装饰。
- 深色只用于少量强调点，不用深色粗线包围全部外轮廓。

### 分层与面积

- 色块应成为第一眼看到的主体，线条不应抢先形成一枚传统工具栏图标。
- 一般让可见主体的大部分面积由两级填色构成；这是视觉判断，不需要计算像素占比。
- 重叠关系应清楚：后方色块、前方浅色主体、主色局部、细线或强调点。
- 根据主题使用 2–3 层即可。不要为了“分层”堆出大量纸片、阴影和碎屑。
- 默认使用纯色和少量透明度，不使用渐变、模糊或投影。参考图明确包含这些效果时再按需调整。

## 默认配色

这套默认色值来自已确认的浅紫创作插画。实现时优先复用统一 token，避免每个 SVG 各调一套紫色。

| 用途 | Token | 浅色主题 | 深色主题 |
| --- | --- | --- | --- |
| 浅层主体／纸面 | `--project-art-surface` | `#f0e9f8` | `#38313f` |
| 主色块／后层 | `--project-art-back` | `#d9c9ed` | `#625576` |
| 细线／局部细节 | `--project-art-detail` | `#aa8bcf` | `#c4acd9` |
| 局部轮廓，可选 | `--project-art-outline` | `#b39acd` | `#9580aa` |
| 条纹细节，可选 | `--project-art-stripe` | `#aa8bcf` | `#bca3d4` |
| 少量强调 | `--project-art-accent` | `#8b65b5` | `#c9afe5` |

使用建议：

- 主体采用 `surface` 和 `back`，线条采用 `detail`。强调色只点到为止。
- 不用一个 `currentColor` 同时控制全部填色与描边，否则会失去插画层次。
- 深色模式单独映射色阶，不对浅色 SVG 整体降低透明度或反色。
- 用户换配色时可以替换 token，但保留浅层、主色块、细节、强调之间的层级。
- SVG 单独导出时给 CSS 变量提供回退值，或导出指定主题的固定色值；不要依赖未定义的页面变量。
- 图标 token 应在图标本身或其祖先作用域生效，不能仅定义在其他插画组件上。

## 尺寸、密度与整套一致性

- 默认可见主体位于约 `x=2…22`、`y=2…22`，为描边端点留出空间。
- 检查真正的曲线极值和描边范围，不只检查路径起点。
- 卡片默认图标为 26×26px；布局占位可为 30×30px，保持透明背景。遵循用户已有尺寸要求。
- 每个图标使用相近的视觉重量和重心；狭长的笔、纸条可稍微倾斜或加大，但不靠外加底板撑面积。
- 同一组不能有的像密集线稿，有的像纯色剪影，有的又像立体按钮。
- 先保证 26px 清楚，再考虑放大时的精致程度。不要只在大尺寸展示图上验收。

## 制作流程

1. **建立语义映射。** 为每项功能选择一个直观物件，必要时用一个辅助元素区分相似项。例如：故事→翻开的书，角色→头肩像，场景→景物层叠，合成→叠页，排字→气泡，审校→文稿与勾选。
2. **先画主轮廓。** 用封闭曲线画浅层主体和主色块，暂不依赖线条。确认物件的大形可辨。
3. **添加结构线。** 只加能帮助理解主题的线条。删掉重复描边、微小格子和无意义纹理。
4. **统一整组。** 对比图标的面积、圆润程度、线宽、留白、重心和色阶，调整明显偏重或偏淡的个体。
5. **在实际界面检查。** 显示原尺寸与适度放大版本，放到白色／浅灰卡片和深色卡片中检查。先修正实际尺寸的模糊与裁切。
6. **交付可复用文件。** 给出 SVG 或项目组件、配色 token 和简短说明。批量输出时提供带名称的预览，方便核对含义与数量。

局部调整或已有明确参考时，直接依据已确认的风格执行，不重复要求用户批准相同风格。若用户只是讨论视觉问题，先说明问题所在，不扩大为整页改版。

## SVG 与组件规范

- 纯 SVG 形状和路径；不要将位图嵌入 SVG 伪装成矢量图标。
- 图标主视觉不依赖文字、Emoji、外部字体或外部图片。
- 装饰性图标设置 `aria-hidden="true"` 与 `focusable="false"`。独立承担功能时，由交互控件提供准确名称。
- 填色路径显式 `stroke="none"`；只为需要的线条设置描边。
- 静态 artwork 可放在模块顶层；统一通过一个组件输出 `viewBox`、尺寸和基础线条属性。
- 使用蒙版、裁切或渐变时保证重复挂载不会产生 ID 冲突；不需要时省略这些结构。
- 无障碍状态、勾选或更多按钮属于界面交互，不混进图标 artwork。
- 默认不新增动画。用户明确要求时，可沿既有图层做轻微错位或短促抖动，并尊重减少动态效果设置。

## 常见偏差及修正

| 看起来不对的地方 | 原因 | 修正 |
| --- | --- | --- |
| 颜色相同但仍不像参考插画 | 只换了色，没有匹配主体与线条比例 | 用色块重构物件，削弱完整外描边 |
| 像功能图标加一团紫色背景 | 色块与物件语义无关 | 把色块变成纸页、杯身、头肩、星球等实际部分 |
| 所有图标像同一种徽章 | 重复添加统一底板 | 去掉底板，让各自主体形成轮廓 |
| 图标灰淡、局部消失 | 色值不对、变量作用域缺失或透明度过低 | 检查实际计算色值，恢复层级，不整体降低透明度 |
| 缩小后显得脏乱 | 内部线条过密 | 删除装饰，保留最关键的结构线 |
| 有机色块像随意涂鸦 | 曲线没有服务于物件 | 根据轮廓和局部结构重画，避免随机曲线 |
| 加粗后变成粗线工具图标 | 用线宽弥补填色不足 | 恢复细线，调整主体填色面积与层次 |

## 完成前验收

- 每项功能有明确、可区分的图标，名称映射无遗漏。
- 主色块使用多样的圆润闭合曲线，并且属于物件本身。
- 保留线条与色块结合的表达，线条不包办整个造型。
- 无额外徽章背景，卡片底色不被图标文件覆盖。
- 与参考插画同时匹配配色、轮廓、分层、视觉重量和细节密度。
- 实际尺寸没有裁切、糊线、过淡或视觉重量悬殊。
- SVG 可解析、变量有定义或回退值；已有项目通过相关类型检查。
- 能够渲染时完成目视检查；工具不可用时明确说明未完成的视觉检查，不把格式校验当作视觉验收。
