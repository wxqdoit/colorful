# 全量圆润修订 · v0.3.1

用户要求：检查所有图标，所有元素要圆角，整体感觉圆润。

- 范围：1,053枚，4,181个regular图形元素。
- 修改：871枚有路径圆角变化，处理7,445处填色或描线路径转角；182枚已圆润。
- 同步：六种样式共6,318枚SVG、CSR/SSR组件及主预览。
- 快照：design/archive/0.3.0-regular 保留修订前版本。对照页现比较0.3.0与0.3.1。

## 做法

不改物件语义或三色分层。在自主设计路径上识别切线不连续的位置，按邻边长度限幅裁入，以切线连续的三次曲线连接。开放描线保留开放端点，多个子路径不互相连接，复合路径保留孔洞方向。圆与已有平滑曲线不重复收缩。线帽、接头及矩形圆角同步检查。

绘制源中的掌形零宽指缝改成实际有间距的四指与圆弧谷底，覆盖5枚手势；synagogue的小型六角星扩大并采用局部0.5圆角和0.85描线，保留六个外围三角空隙。制作提示不会进入运行时SVG。

## 验证

所有分组完成26/56px全量联系表目视检查，描线新增修改逐组二次复查。详细记录见 core-review.md、nature-review.md、objects-review.md、people-review.md。

npm run check：生成同步、全6,318样式圆角检测、TypeScript、25项单元测试、构建、真实安装包入口/SSR/类型/UMD/tree-shaking及示例双入口构建。

检测使用1°切线夹角容差，以容纳序列化数值误差；并非仅看路径命令有没有C/Q/A。测试覆盖直线/曲线接点、闭合缝、凹角、复合孔洞、开放描线、继承填色与零矩形半径。

维护时运行 npm run redesign 会执行绘制源、圆角处理、组件生成与对照页更新；npm run test:roundness 用于防止新增硬角。
