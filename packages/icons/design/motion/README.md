# 分层悬停动画 · v0.4.0

hover 的外层不再运动。构建时将每个原始图形包装为独立的动画层，按原始三色语义标注 back / surface / detail；双色模式仍使用原始角色，不因颜色合并而失去层级。图形顺序、几何属性及原有 transform 不变，静态 SVG 素材不增加动画。

四种动作：分层浮起、交错轻摆、错峰呼吸、分层舒展。后层幅度小，主体和细节使用不同幅度；角色延迟叠加部件错峰。悬停后保持动作终态，移出立即启动平滑归位，避免无休止循环。

五种缓动：柔和、舒缓、利落、弹性回弹、匀速。默认时长 600ms、错峰基准 45ms，均可从 props、IconContext 和预览页设置。

镜像与初始动画保留独立变换层；鼠标悬停、按钮键盘焦点和可聚焦 SVG 都能触发。减少动态效果时禁用部件运动，保留最终镜像方向。静态导出会移除全部动画标记。

## 色块轮廓形变 · v0.4.1

新增 `hoverAnimation="morph"`，作为预览页默认动作。直接插值色块轮廓的 `d` 路径，不改变外层或部件 transform；细节色与描线保持稳定。后层与主体采用反向的轻微曲面弯曲，沿用五种缓动、时长及错峰配置。

在构建时为圆、椭圆、圆角矩形和填充路径生成一致的三次贝塞尔命令。静态素材不变；组件里的基本图形转换为等效路径（圆弧使用标准贝塞尔近似）。精确分割长曲线、处理退化端点与微小闭合接缝，形变时保持平滑切线。全量测试验证命令对应、静态边界/面积、各闭合轮廓方向及形变圆角。六种粗细复用同一份形变数据，继续按图标加载。

实现依据：[SVG 路径插值要求](https://www.w3.org/TR/SVG/paths.html) 和 [CSS d 属性](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/d)。不支持 CSS d 插值的浏览器显示原始静态色块。减少动态效果时固定原形；静态导出清除形变变量和动画标记。

## 软糖弹性语言 · v0.5.0

动作语法统一为 0% 原形 → 14% 反向挤压蓄力 → 42% 释放 → 66% 回摆 → 84% 小回摆 → 100% 落定。主体色块先行动，前层和细节分别跟进；默认 900ms，错峰基准 65ms。一次触发完成一段动作，悬停期间不无限循环。

五个动作保留原 API 值：软糖回弹 morph（挤压伸展结合真实轮廓鼓起）、轻跃登场 lift（下压后跳起）、俏皮摇摆 wiggle（反向预摆与左右衰减）、气泡鼓起 pulse（压扁后竖向鼓起）、纸片绽放 spread（收拢后分层散开）。形变幅度上限提高至 x 1.65 / y 1.35 个画布单位，细节稍晚响应，保留三色和圆润形态。

形变路径只在原形与形变态之间插值；蓄力与反向回摆由各层的挤压、伸展、位移和旋转承担，避免负向路径外推翻转退化切线。原生 Web Animations 仅作用于部件和色块路径；镜像与初始动画互不争用。中断时先读取当前姿态，再用最长 320ms 收回。卸载、配置更换、减少动态效果会取消本库动画并清理监听。新增 hoverReplayKey 用于手动重播，预览页提供三枚示例的动效试验台。

实现参考：[Element.animate](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate)。不引入动画依赖，不使用逐帧 React 状态更新。纯 SSR 组件使用 CSS 回退，完整编排由客户端组件提供。
