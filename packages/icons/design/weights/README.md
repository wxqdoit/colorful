# 六种样式修订 · v0.3.2

色块模式原来直接删除无填充的路径，误删了书脊、时针、箭头、车架等识别结构。现在保留全部语义元素，并用同色圆润边缘增加色块饱满度：主体 0.55，细节点 0.2，不增加第四种颜色。

四档结构线宽从 1.0 / 1.05 / 1.1 / 1.25 调整为 **0.45 / 0.75 / 1.1 / 1.8**（24 单位画布）。局部调细的线条也同比例变化。纯色块主体保持原轮廓，线宽控制结构线与描线。

[六种样式对照](comparison.png) 包含 12 枚代表图标的 48px / 26px 预览。

全量检查 1,053 枚色块模式与标准模式的图形数量和几何属性一致；6,318 个变体计入变换和实际线宽的几何边界检查无越界。

复查边界：`node design/weights/check-bounds.mjs`（在项目根目录运行）。
